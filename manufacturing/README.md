# Manufacturing

Everything needed to make and assemble the robot.

| Folder | Holds |
|---|---|
| `drawings/` | Released drawing PDFs, with the revision in the file name |
| `machining/` | CAM files, setup sheets, tooling and fixture notes |
| `3d-printing/` | Print profiles and settings per part: material, orientation, walls, infill |
| `finishing/` | Finish specifications per part: anodising, plating, heat treatment, paint |
| `assembly/` | Assembly instructions, fastener torques, grease and preload notes, alignment and calibration steps |

Not started.

## Rules

- A file here is a release, not work in progress. The source stays in `cad/`.
- A released file is never overwritten. A change is a new revision with a new file name.
